# 答辩问题与回答

**Q：学生画像是否是对话式构建？**  
A：是。系统通过多轮自然对话抽取画像，并持续沉淀到 6 个维度：知识基础、认知风格、学习偏好、易错点、学习进度、情感动机。

**Q：是否只有文本资源？**  
A：不是。当前资源包包含讲义、思维导图、练习题、HTML/SVG 动画、视频讲解脚本、语音讲解资源、代码案例和项目任务。动画可以直接在前端安全预览。

**Q：科大讯飞工具如何体现？**  
A：后端实现了讯飞 TTS 配置项、状态接口和服务封装。无 Key 时返回 `not_configured` 并稳定降级；有 Key 时可进入真实 TTS 调用路径。星火和安全审核作为可插拔扩展暴露状态。

**Q：测评后如何动态调整？**  
A：测验提交后会生成 `evaluation` 和 `path_adjustment`，其中包含错因、薄弱点、新增任务、推荐资源和下一步学习建议，前端测验页和学习路径页都能展示。

**Q：如何降低 AI 幻觉风险？**  
A：系统要求 AI 内容尽量绑定课程知识库引用，并通过敏感词、绝对化表达、引用覆盖和人工复核规则审核。AI 生成内容需教师或管理员确认后进入正式资源。
