# EduMind 提交包目录结构建议

## 1. 推荐提交目录

```text
EduMind/
├─ backend/
├─ frontend/
├─ miniprogram/
├─ docs/
│  ├─ course_kb/
│  ├─ submission/
│  ├─ screenshots/
│  ├─ demo-checklist.md
│  └─ miniprogram-guide.md
├─ reports/
├─ scripts/
├─ README.md
├─ start-dev.bat
├─ stop-dev.bat
├─ seed-demo-data.bat
└─ check-demo-ready.bat
```

## 2. 建议附加材料

- 演示视频：建议 5 到 7 分钟，命名为 `EduMind_演示视频.mp4`。
- 答辩 PPT：建议命名为 `EduMind_答辩PPT.pptx`。
- 截图素材：放入 `docs/screenshots/`。
- 验收报告：保留 `docs/reports/demo_ready_check.md` 和 `reports/demo_flow_check.md`。

## 3. 建议不提交内容

- `node_modules`
- `frontend/dist`
- `.env`
- 本地数据库文件
- 上传文件
- 运行日志
- IDE 缓存
- 操作系统临时文件

## 4. 提交前检查

提交前建议执行：

```bash
cd frontend
npm run build
```

```bash
python scripts/check-demo-ready.py --backend-url http://127.0.0.1:8000 --frontend-url http://127.0.0.1:5173
```

```bash
python scripts/e2e_demo_flow_check.py --base-url http://127.0.0.1:8000 --output reports/demo_flow_check.md
```

## 5. 说明

如果比赛平台限制提交包大小，可优先提交源码、文档、演示数据、README、PPT 和演示视频，不提交构建产物和依赖缓存。
