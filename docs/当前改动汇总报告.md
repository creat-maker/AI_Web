# EduMind 当前改动汇总报告

## 1. 文档目的

本文档用于汇总最近几轮对 EduMind 的优化与修复工作，重点说明改动范围、涉及文件、业务影响、验收结果和后续提交建议。

本轮工作整体目标不是重构系统，也不是接入新的外部大模型，而是围绕答辩前的可用性、完整性、可信表达和页面质感做低风险收口。

## 2. 总体改动概览

本次累计改动可以分成十类：

| 类别 | 主要目标 | 用户侧效果 |
| --- | --- | --- |
| 登录页优化 | 将登录页从入口卡片升级为正式产品风格页面 | 登录页更像成熟教育 SaaS 产品，支持三角色快捷登录和手动登录 |
| 课程管理闭环 | 修复新建课程像前端假功能的问题 | 新建课程会调用后端接口，刷新后仍可保留，能进入资源等链路 |
| 搜索能力补齐 | 处理多个页面搜索框只绑定输入、不真实过滤的问题 | 搜索按钮、回车、清空、无结果状态均有反馈 |
| 资源生成闭环 | 保证管理员/教师生成资源后学生端可读取 | 资源生成、列表查看、学生资源页形成闭环 |
| 报告中心增强 | 修复报告预览、下载、审核入口不完整的问题 | 教师端和管理员端报告操作更完整 |
| Agent 工作流增强 | 保留并增强工作流 trace、warnings、evidence、confidence | 评委可看到可追溯的智能体执行过程 |
| 系统状态与能力说明 | 将状态页和能力页换成正式产品口径 | 不再像未完成说明，改为运行状态、能力边界、生产化接入路径 |
| 权限与路由守卫 | 保留三端 session、路由守卫和无权限页 | 不同角色跳转和访问边界更清楚 |
| 可见文案清理 | 清理用户可见的低质量表达 | 页面、菜单、文档更像完整产品 |
| 文档与验收 | 更新 README/docs，并运行构建和后端检查 | 便于答辩前复核和提交 |

## 3. 登录页改动

### 3.1 涉及文件

| 文件 | 改动说明 |
| --- | --- |
| `frontend/src/views/Login.vue` | 重做登录页结构、文案、视觉层级、角色切换、快捷入口、响应式样式 |
| `backend/app/api/routers/auth.py` | 增加正式短账号兼容：`student`、`teacher`、`admin`，保留原有 `demo_*` 账号兼容 |

### 3.2 登录页视觉优化

登录页由原先偏“后台入口 / 表单原型”的结构，改为现代教育 SaaS 风格：

- 桌面端采用左右分屏布局。
- 左侧约 56% 到 60%，用于品牌、主标题、核心业务链路和三端能力说明。
- 右侧约 40% 到 44%，用于聚焦登录操作。
- 背景使用柔和浅蓝、浅紫和白色渐变。
- 增加轻量模糊光感背景块，提升层次，但没有复杂动画。
- 主卡片使用白色玻璃质感、柔和阴影和细边框。
- 圆角、阴影、边框、字体大小和间距重新统一。

### 3.3 左侧品牌区

左侧按照“品牌 -> 核心价值 -> 业务链路 -> 能力卡片”的顺序重排：

- 品牌标识：`EduMind Studio`。
- 副标题：面向学生、教师、管理员的教育智能体平台。
- 主标题：围绕 Python 循环结构的个性化教学闭环。
- 简短说明：聚合课程学习、资源生成、智能辅导、测评分析与报告治理。
- 核心业务链路步骤条：
  - 画像诊断
  - 路径规划
  - 资源推荐
  - 智能辅导
  - 测验评价
  - 报告生成
  - 平台治理
- 三端 feature cards：
  - 学生端：学习路径、资源推荐、智能答疑、学习报告
  - 教师端：课程管理、资源生成、画像分析、学情报告
  - 管理员端：资源治理、内容审核、用户角色、系统状态

### 3.4 右侧登录卡片

右侧登录卡片做了这些调整：

- 顶部增加 `Welcome back` 和“登录 EduMind Studio”。
- 角色选择从普通按钮升级为三段 selectable cards。
- 当前选中角色有明显高亮、颜色、阴影和背景层级。
- 输入框高度增加，圆角更统一，focus 状态更清晰。
- 主按钮改为品牌蓝渐变按钮。
- 主按钮文案随角色变化：
  - 进入学生端
  - 进入教师端
  - 进入管理员端
- loading 状态禁用重复点击，并显示“正在进入...”。
- 错误提示改为卡片内友好提示，不使用粗糙弹窗。
- 快捷登录和辅助入口重新分层：
  - 第一组：学生端 / 教师端 / 管理员端快捷登录
  - 第二组：系统状态 / 平台能力

### 3.5 登录逻辑

保留了原有流程：

1. 角色卡片点击后，自动填入对应账号密码。
2. 点击主登录按钮或快捷登录后，调用 `/api/v1/auth/login`。
3. 登录成功后写入 `edumind.accessToken`。
4. 调用 `useRole().setRole(role)` 设置当前角色 session。
5. 学生端设置对应学生 id。
6. 按角色跳转：
   - 学生端：`/student`
   - 教师端：`/teacher`
   - 管理员端：`/dashboard`

没有改认证架构，没有改路由守卫，没有新增大型依赖。

## 5. 搜索功能补齐

### 5.1 总体原则

修复多个页面“搜索框只是 UI”的问题，统一做到：

- 输入关键词后真实过滤列表、表格或卡片。
- 支持点击搜索按钮。
- 支持回车搜索。
- 支持清空后恢复全量。
- 支持中文关键词。
- 支持无结果空态。
- 对数组、对象字段会转成字符串参与搜索。
- 不再只打印 `console.log` 或无 UI 变化。

### 5.2 涉及页面

| 页面 | 搜索字段 | 实现方式 |
| --- | --- | --- |
| 首页 / Dashboard | 课程、资源、功能入口、状态、描述 | 前端 computed 过滤 |
| 课程管理 | 课程名称、课程编号、教师、状态、知识点、简介 | 前端过滤 + 后端数据 |
| 管理员课程 | 名称、编号、教师、状态、标签、学科 | 前端过滤 + 后端数据 |
| 学生资源页 | 课程、章节、资源类型、标题、知识点、状态 | 前端过滤 + 后端资源数据 |
| 管理员资源生成中心 | 课程、章节、类型、状态、关键词 | 前端过滤 + 生成结果刷新 |
| 知识库页面 | 文档名、课程、章节、状态、关键词 | 前端过滤 |
| 学生画像 / 用户角色 | 姓名、角色、学习水平、风险等级、班级 | 前端过滤 |
| 日志管理 | 日志类型、模块、关键词、状态 | 前端过滤 |
| 报告中心 | 学生、课程、章节、报告类型、关键词 | 前端过滤 |

### 5.3 特别验收点

- 搜索“循环”可以筛出 Python 循环结构相关课程、资源或内容。
- 搜索不存在词时显示“未找到相关内容 / 资源 / 课程”等空态。
- 清空搜索后恢复完整列表。

## 12. 占位与假按钮处理

- 主菜单入口不允许空白、404 或点击无反应。

- 不在主链路中的入口不再伪装成已完整生产能力。

- 首页入口、Dashboard 快捷入口、右上角入口均保持可用。
- 个人中心、账号设置、帮助中心、无权限页可正常打开。
- PlaceholderPage 文案正式化，避免像未完成页面。
- 不保留明显的空按钮、空方法或低质量提示。

## 15. 关键业务链路说明

### 15.1 登录链路

```text
登录页选择角色
-> 自动填充账号密码
-> 调用 /api/v1/auth/login
-> 写入 accessToken
-> useRole 设置角色 session
-> router 跳转角色首页
-> 路由守卫控制访问边界
```

### 15.2 课程创建链路

```text
教师端 / 管理员端点击新建课程
-> 前端表单校验
-> POST /api/v1/courses
-> 后端写入 SQLite 或当前存储
-> 前端刷新课程列表
-> 新课程可搜索
-> 资源生成页课程选择可见
-> Dashboard / 课程详情下次加载可读取
```

### 15.3 资源生成链路

```text
管理员 / 教师选择课程和资源类型
-> 调用资源生成接口
-> 后端生成结构化资源包
-> 写入 GeneratedResource
-> 管理端资源列表可见
-> 学生端学习资源页可读取
-> 搜索关键词可筛选新资源
```

### 15.4 报告链路

```text
教师端或学生端触发报告查看 / 生成
-> 后端报告服务组织学习数据和建议
-> 前端报告中心展示列表
-> 可打开预览弹窗
-> 可下载报告
-> 管理员端可进入报告审核中心查看质量和证据链
```

### 15.5 Agent 工作流链路

```text
管理员端进入 Agent 工作流
-> 运行完整学习流程
-> 返回画像、证据、路径、资源、测验、报告线索
-> 前端展示 trace / warnings / evidence / confidence
-> 便于说明智能体链路可追踪
```

## 20. 总结

这几轮优化的核心价值是把 EduMind 从“页面能打开但部分像样例或半成品”的状态，推进到“主链路能真实走通、搜索有反馈、课程和资源能闭环、报告可预览下载、Agent 工作流可追踪、系统状态和能力边界表达正式、登录页具备成熟产品质感”的状态。

整体上，当前系统更适合答辩现场按三端链路讲解：

```text
学生端：画像诊断 -> 学习资源 -> 智能答疑 -> 测验评价 -> 学习报告
教师端：课程管理 -> 资源生成 -> 学情分析 -> 报告中心
管理员端：资源治理 -> 内容审核 -> 用户角色 -> 日志管理 -> 系统运行状态
```
