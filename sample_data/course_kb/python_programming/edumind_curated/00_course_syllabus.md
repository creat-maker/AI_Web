# Python 程序设计：从基础语法到爬虫实践

## 课程目标

本课程面向高校计算机、软件工程和人工智能相关专业学生，目标是帮助学生掌握 Python 程序设计的核心语法、常用数据结构、函数模块化、文件与异常处理、面向对象思想，并能完成一个小型网络数据采集项目。

## 知识模块

1. Python 基础环境与第一个程序：解释器、脚本运行、注释、输入输出。
2. 变量、数据类型与表达式：整数、浮点数、字符串、布尔值、类型转换、运算符。
3. 分支与循环：`if`、`elif`、`else`、`for`、`while`、`break`、`continue`。
4. 常用数据结构：列表、元组、字典、集合及其典型使用场景。
5. 函数与模块：函数定义、参数、返回值、作用域、模块导入。
6. 文件读写与异常处理：`open`、`with open`、文本文件、JSON、`try-except-finally`。
7. 面向对象基础：类、对象、属性、方法、封装和简单继承。
8. 网络爬虫实践：HTTP 请求、状态码、请求头、网页解析、数据保存和合规要求。

## 学习路径建议

基础薄弱学生应先完成变量、分支、循环和数据结构练习，再进入文件与异常处理。具备基础的学生可以直接从函数、模块和项目化任务入手。对爬虫感兴趣的学生需要先理解 HTTP 请求响应模型，再学习 `requests`、BeautifulSoup 和数据保存。

## 课程资源类型

- 个性化讲义：围绕学生薄弱点解释概念。
- 思维导图：展示知识点前置关系。
- 分层练习题：基础题、迁移题和综合题。
- 代码案例：可运行的 Python 示例。
- 实践项目：小型数据采集、日志分析或成绩分析任务。
