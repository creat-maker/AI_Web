# EduMind 答辩演示脚本

## 1. 7 分钟演示节奏

### 0:00 - 0:40 项目定位

介绍 EduMind 是面向个性化学习资源与教学智能体平台的演示系统，包含 Web 三端和原生微信小程序学生端。强调当前版本为比赛演示版本，不声称正式上线，不接真实大模型 API。

### 0:40 - 1:20 登录与三端入口

打开 `/login`，展示学员、教师、管理员三个入口。说明角色切换只在登录页完成，进入角色后侧边栏只显示对应菜单。

### 1:20 - 2:30 学生学习闭环

进入 `/student`，依次展示学习总览、我的课程、学习路径。重点进入 `/student/assistant`，展示：

- 对话式学习画像。
- 5 类个性化资源。
- RAG 引用问答。
- 引用来源和可信度。
- 推荐练习。
- 防幻觉审核结果。

### 2:30 - 3:20 教师教学干预闭环

进入 `/teacher`，展示班级概览、课程管理、学生画像、学习路径与测评分析。说明教师可根据画像和测评结果进行教学干预。

### 3:20 - 4:30 管理员治理闭环

进入 `/dashboard`，展示平台总览。进入 `/resource-generation` 展示 AI 内容审核 / 防幻觉审核。进入 `/agent-workflow` 展示六步执行链路。

### 4:30 - 5:30 小程序学生端

用微信开发者工具展示小程序首页、资源推荐、AI 辅导和学习报告。说明小程序优先请求后端接口，失败时自动 fallback 到本地 demoData，保证现场稳定。

### 5:30 - 6:20 demo-status 与验收脚本

打开 `/demo-status`，展示 Web 三端、小程序、画像、资源生成、课程知识库、RAG、防幻觉、Agent 执行链路均为 Ready。展示 `check-demo-ready` 和 `e2e_demo_flow_check` 报告。

### 6:20 - 7:00 总结创新点与扩展方向

总结核心创新：

- 双端演示：Web 三端 + 原生小程序。
- 画像驱动资源生成。
- 课程知识库 RAG 引用。
- 防幻觉审核和可信度评分。
- Agent 六步链路展示。

说明后续可扩展到真实大模型 API、向量数据库、生产级工作流和持久化审核记录。

## 2. 备用演示路径

如果后端不可用：

- Web 页面仍可展示大部分 fallback 数据。
- 小程序可使用本地 demoData。
- 可直接展示 README、demo-status 截图和验收报告。

## 3. 答辩常见问题

### 是否接入真实大模型？

当前没有接入真实大模型 API。为保证比赛现场稳定，采用规则化生成、轻量 RAG 和可解释审核逻辑。接口结构保留后续接入大模型能力。

### 是否使用向量数据库？

当前没有使用向量数据库，RAG 使用关键词匹配和规则排序。后续可替换为 Chroma、FAISS 或生产级检索服务。

### 防幻觉如何实现？

通过引用覆盖、无引用风险、绝对化承诺和无依据结论检测进行审核，返回风险等级、可信度和修改建议。

### Agent 是否是真实工作流引擎？

当前为规则化 Agent 执行链路演示，展示教育智能体的关键步骤和数据流。后续可升级为生产级编排框架。
