# 参赛项目说明书

EduMind 面向 Python 程序设计课程，提供学生画像、个性化路径、资源生成、智能答疑、测评反馈、内容审核和学习报告闭环。

本轮对齐重点：

- 学生画像：对话式构建，包含知识基础、认知风格、学习偏好、易错点、学习进度、情感动机 6 个维度。
- 多模态资源：至少 8 类资源，包含可预览 HTML/SVG 动画、视频讲解脚本和语音讲解资源任务。
- 科大讯飞工具：支持 TTS 接入路径、星火大模型扩展路径和内容安全扩展路径；当前运行环境无密钥时使用本地智能评测引擎。
- 测评闭环：测验提交后返回评价、错因、推荐资源和学习路径调整摘要。
- 防幻觉机制：课程知识库引用、规则审核、引用覆盖检查和人工复核。

能力边界：当前版本不宣称完整生产级数字人视频或完整生产级 AI 服务；真实学校部署可继续接入统一身份认证、向量数据库、学校数据平台和审计日志。
