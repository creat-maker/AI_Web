# 论文到 EduMind 功能模块映射

## 功能模块总览

| EduMind 功能模块 | 主要论文支撑 | 可落地设计 |
|---|---|---|
| 学习者画像 | 肖君等《大数据环境下在线学习者画像的构建》、师亚飞等《基于学习画像的精准个性化学习路径生成性推荐策略研究》、Solari 等兴趣分析指南 | 建立基础信息、学习行为、知识掌握、兴趣动机、学习路径、风险标签六类画像 |
| 个性化学习路径 | 刘昕等《一人一堂的个性化课堂》、TutorLLM、Electronics KG 路径综述、Applied Sciences 第二课堂路径推荐 | 基于知识图谱和掌握度动态生成下一学习元，按前后测/错题/行为反馈更新路径 |
| 学习资源推荐 | PLORS、本体推荐模型、K12 推荐综述、英语资源协同过滤论文 | 为资源建立知识点、难度、类型、先修关系、适用画像标签；用混合推荐输出资源 |
| RAG 知识库问答 | KG-RAG、NotebookLM RAG 导师、RAG-PRISM、课程 Chatbot 构建方式 | 课程资料入库，结合知识图谱检索；回答附来源、知识点、可信度和追问建议 |
| 知识图谱 | 张勇等《基于学科知识图谱的高校教学模式研究》、2401 KG 构建论文、Electronics KG 综述 | 抽取课程知识点与关系，绑定资源、题目、错题和学生掌握度，支持路径解释 |
| 多智能体教育系统 | von Neumann MAS、LLM Agents for Education、VITA 虚拟助教 | 拆分诊断 Agent、推荐 Agent、答疑 Agent、资源生成 Agent、审核 Agent、教师助理 Agent |
| 生成式教学资源 | Generative AI for Customizable Learning Experiences、孙立会等生成式 AI 平台实践逻辑、赵晶等教学资源库 | 根据知识点、难度和学生画像生成讲解、例题、练习、反馈和复习资料 |
| 教师诊断与学习分析 | 智慧教育研究现状与发展趋势、VITA、数智化个性化学习综述、Data-driven personalized teaching | 教师看板展示班级薄弱知识点、高风险学生、推荐效果、干预建议和形成性评价 |
| 内容审核与质量控制 | RAG 原创性评价、RAG-PRISM、LLM Agents 综述 | 检查作业相似度、AI 回复依据、内容对齐、幻觉风险、敏感内容和引用来源 |

## 答辩材料优先级

### 第一优先级：直接支撑 EduMind 核心闭环

1. `2402.01666v2.pdf`：定义个性化学习、学生建模和推荐全景。
2. `基于学习画像的精准个性化学习路径生成性推荐策略研究_师亚飞.pdf`：支撑画像驱动动态路径。
3. `一人一堂的个性化课堂_刘昕.pdf`：支撑“一人一课”产品叙事。
4. `2311.17696v7.pdf`：支撑 KG-RAG 智能导师，且有实验结果。
5. `基于学科知识图谱的高校教学模式研究_张勇.pdf`：支撑知识图谱构建和教学应用。

### 第二优先级：支撑技术亮点

6. `2502.15709v2.pdf`：知识追踪 + RAG，适合说明个性化问答不是普通 Chatbot。
7. `2503.11733v2.pdf`：多智能体教育综述，支撑 Agent 架构。
8. `2501.00083v1.pdf`：多智能体框架，支撑任务分解、记忆、工具调用。
9. `2509.20369v1.pdf`：形成性评价和教师看板。
10. `education-15-00706.pdf`：RAG 原创性评价和质量控制。

### 第三优先级：支撑背景、合规与扩展

14. `s40561-026-00440-6.pdf`：AI 时代个性化学习术语定义。
15. `s44163-025-00598-x.pdf` 与 `higheredu-04-00017.pdf`：系统综述和风险讨论。
