# 测试说明书

本文档记录 EduMind A3 主演示版本的基础验证方式。主演示口径统一为《Python 程序设计》循环结构章节，学生为李明，画像为“基础薄弱 + 代码实操偏好型，中风险”。

## 一、推荐测试环境

- 后端建议使用项目根目录下的 `.venv`。
- 前端使用 `frontend/package.json` 中锁定的 npm 脚本。
- 默认系统 Python 如缺少 FastAPI，请使用 `.venv\Scripts\python.exe`。

## 二、后端编译检查

在项目根目录执行：

```bash
python -m compileall backend/app
```

本次审计验证结果：通过。后端 `backend/app` 下模块可以完成 Python 编译检查。

## 三、前端构建检查

在项目根目录执行：

```bash
cd frontend
npm.cmd run build
```

本次审计验证结果：在正常权限下通过，执行内容为 `vue-tsc --noEmit && vite build`。

说明：PowerShell 下直接执行 `npm run build` 可能受执行策略影响，建议使用 `npm.cmd run build`。在受限沙箱内，esbuild 可能因路径读取权限失败；这属于运行环境权限问题，不代表项目源码构建失败。

## 四、关键接口探测

建议使用 FastAPI TestClient 探测以下接口：

- `GET /api/v1/student-profile/demo`
- `POST /api/v1/student-profile/refresh`
- `POST /api/v1/profile-dialog/run`
- `POST /api/v1/resources/generate-pack`
- `POST /api/v1/ai-tutor/ask`
- `POST /api/v1/ai-tutor/digital-human-script`
- `POST /api/v1/rag/ask`
- `POST /api/v1/content-review/check`
- `GET /api/v1/agent-workflow`
- `POST /api/v1/agent-workflow/run-full-learning-flow`
- `GET /api/v1/decision-center/overview`

本次审计验证结果：使用项目 `.venv` 的 FastAPI TestClient 探测关键接口通过。

## 五、Agent 工作流载荷说明

`POST /api/v1/agent-workflow/run-full-learning-flow` 有明确必填字段。简化载荷会返回 422，这是接口 schema 校验结果。

完整载荷示例：

```json
{
  "course_id": 1,
  "student_name": "李明",
  "current_level": "基础薄弱",
  "learning_goal": "掌握 Python 循环结构并完成基础代码实操",
  "weak_points": ["while 循环终止条件", "break / continue 使用", "循环嵌套变量跟踪"],
  "learning_preference": "代码实操偏好型",
  "question": "while 循环为什么会死循环？"
}
```

本次审计验证结果：完整 UTF-8 载荷可返回 200。

## 六、页面验收重点

- 登录页：不出现旧主演示口径，入口聚焦李明、Python 循环结构、A3 教学闭环。
- 学生首页：是李明学习驾驶舱，不是普通菜单。
- 教师分析：围绕循环结构学情、李明风险和干预建议。
- 报告中心：展示 Python 循环结构形成性评价报告。
- 内容审核：状态统一为通过、需修改、人工复核、风险拦截。
- 小程序：需在微信开发者工具中检查 home/path/resources/tutor/quiz/report/profile-dialog 页面。
