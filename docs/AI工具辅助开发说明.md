# AI 工具辅助开发说明

本项目在开发过程中使用 AI Coding 工具辅助代码生成、重构建议、文档整理和测试辅助。AI 工具用于提高实现效率，不替代团队对业务逻辑、演示口径和提交材料的最终确认。

## 一、AI 工具参与范围

- 根据既定 A3 主线生成或修改页面文案。
- 辅助整理后端 mock 数据和接口示例。
- 辅助生成测试说明、部署说明和演示脚本。
- 辅助发现旧场景残留文案并给出清理建议。
- 辅助编写或检查基础验证命令。

## 二、人工确认范围

- 主演示课程、章节、知识点、学生画像和风险等级由团队确认。
- 核心业务逻辑和接口行为由团队人工审查。
- 代码需经过运行验证后再进入提交材料。
- PPT、演示视频和答辩表述由团队最终确认。
- 不将 AI 输出直接作为未经审核的最终事实依据。

## 三、内容审核原则

AI 生成资源、测评结论、学生干预建议和数字人讲解脚本必须经过教师或管理员复核。系统内置内容审核口径为：通过、需修改、人工复核、风险拦截。

## 四、本轮辅助开发说明

本轮 AI 辅助工作仅用于“演示口径清理与一致性修复”，未新增复杂真实大模型 API 依赖，未重构架构，未删除核心模块。
