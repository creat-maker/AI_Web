# Python 常用数据结构

## 列表 list

列表适合保存有顺序、可变长度、允许重复的数据。例如学生成绩、任务清单、爬虫采集到的新闻标题都可以使用列表保存。

### 常用操作

```python
scores = [86, 92, 75]
scores.append(88)
first_score = scores[0]
for score in scores:
    print(score)
```

列表支持索引、切片、追加、删除、排序和遍历。列表是可变对象，修改列表内容会影响原对象。

## 字典 dict

字典适合保存键值对数据，便于通过唯一键快速查找值。例如学生画像、HTTP 请求头、配置项、词频统计都适合使用字典。

### 常用操作

```python
student = {"name": "张三", "level": "基础薄弱", "weak_point": "循环结构"}
student["goal"] = "完成爬虫项目"
print(student["name"])
```

字典的键必须是不可变类型，如字符串、数字、元组。字典不适合保存大量只关心顺序的数据。

## 列表和字典的区别

列表强调顺序，适合“按位置访问”和“批量遍历”；字典强调映射，适合“按名称查找”和“结构化描述”。如果问题是“第几个元素是什么”，优先考虑列表；如果问题是“某个字段对应什么值”，优先考虑字典。

## 集合 set

集合适合去重和集合运算。例如统计不同的错误类型、不同的知识点标签，可以使用集合。

```python
weak_points = {"循环结构", "文件读写", "循环结构"}
print(weak_points)  # {"循环结构", "文件读写"}
```

## 常见错误

1. 把列表下标写越界，例如访问 `scores[10]`。
2. 访问字典不存在的键，导致 `KeyError`。
3. 混淆列表的顺序访问和字典的键访问。
4. 在循环遍历列表时同时删除元素，导致结果不符合预期。
