# 赛题要求对照表

EduMind 是基于大模型的“一人一堂”个性化资源生成与学习多智能体系统。

| 赛题能力 | 对应页面 | 对应接口 / 目录 |
| --- | --- | --- |
| 对话式学习画像 | `frontend/src/views/StudentProfile.vue`、`frontend/src/views/ProfileDialog.vue` | `POST /api/v1/profile-dialog/run`、`GET /api/v1/student-profile/demo`、`POST /api/v1/student-profile/refresh` |
| 多智能体资源生成 | `frontend/src/views/ResourceGenerate.vue`、`frontend/src/views/AgentWorkflow.vue` | `POST /api/v1/resources/generate-pack`、`GET /api/v1/agent-workflow` |
| 个性化路径规划 | `frontend/src/views/StudentLearningPath.vue`、`frontend/src/views/LearningPath.vue` | `GET /api/v1/student/learning-tasks`、`GET /api/v1/learning-paths` |
| 智能辅导 | `frontend/src/views/StudentAssistant.vue`、`miniprogram/pages/tutor` | `POST /api/v1/ai-tutor/ask`、`POST /api/v1/ai-tutor/digital-human-script`、`POST /api/v1/rag/ask` |
| 学习效果评价 | `frontend/src/views/StudentExamResult.vue`、`frontend/src/views/StudentReport.vue`、`frontend/src/views/TeacherAnalysis.vue`、`frontend/src/views/ReportCenter.vue` | `GET /api/v1/reports`、`POST /api/v1/quizzes/submit` |
| 防幻觉审核 | `frontend/src/views/AdminContentReview.vue`、资源卡片审核状态 | `POST /api/v1/content-review/check`、`GET /api/v1/content-review/records` |
| Python 课程知识库 | `frontend/src/views/KnowledgeBase.vue`、`frontend/src/views/AdminKnowledge.vue` | `data/course_knowledge/python_programming/`、`docs/course_kb/python_programming.json` |
| 小程序展示 | `miniprogram/pages/home`、`path`、`resources`、`tutor`、`quiz`、`report` | 小程序本地 mock + `miniprogram/utils/demoData.js` |
| 教学智能决策中心 | `frontend/src/views/TeachingDecisionCenter.vue` | `GET /api/v1/decision-center/overview` |

主演示课程统一为《Python 程序设计》，章节为“循环结构”，知识点为 for 循环、while 循环、break / continue、循环嵌套，学生为“李明”。
