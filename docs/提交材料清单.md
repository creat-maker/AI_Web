## Contest Hard Requirement Markers

- Dialogue profile construction: backend and frontend expose 6 dimensions: knowledge_base, cognitive_style, learning_preference, error_prone_points, learning_progress, emotional_motivation.
- Multimodal resources: resource packs include handout, mindmap, quiz, animation_html, video_script, tts_audio, code_case, project_task.
- Xfyun tools: `.env.example`, backend config, service wrappers, and `/api/v1/xfyun/status` cover TTS, Spark, and Safety; without keys, EduMind uses the local intelligent evaluator.
- Assessment loop: quiz submission returns `evaluation`, `path_adjustment`, added tasks, recommended resources, and next learning step.
- Content safety: knowledge citations, citation coverage, rule-based review, manual review, and configurable Xfyun safety are documented and surfaced.
