# 科大讯飞工具使用说明

系统预留并实现了可配置的科大讯飞接入路径，当前优先支持 TTS 语音合成，并提供星火大模型和内容安全扩展的状态封装。

环境变量：

```env
XFYUN_ENABLED=false
XFYUN_APP_ID=
XFYUN_API_KEY=
XFYUN_API_SECRET=
XFYUN_TTS_URL=wss://tts-api.xfyun.cn/v2/tts
XFYUN_SPARK_URL=wss://spark-api.xf-yun.com/v3.5/chat
XFYUN_SAFETY_URL=https://spark-api.xf-yun.com/v1/safety
```

运行规则：

- 未配置密钥时，`/api/v1/settings` 和 `/api/v1/xfyun/status` 返回 `not_configured`。
- 未配置密钥时，资源生成仍返回文本讲解、TTS 任务状态和本地资源，不会伪装成已生成真实音频。
- 配置密钥后，`XfyunTTSService` 具备签名 URL 生成和 TTS 调用封装；若运行环境缺少 WebSocket 客户端，会返回明确失败状态，不影响后端启动。
- 星火和内容安全服务作为可插拔 AI 服务状态暴露，生产环境可继续接入真实请求。
