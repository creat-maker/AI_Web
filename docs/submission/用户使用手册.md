# EduMind 用户使用手册

## 1. 登录入口

访问 `/login` 进入 EduMind Studio 登录页。当前为演示级角色入口，不做复杂 token 鉴权。

可选择：

- 学员登录：进入 `/student`。
- 教师登录：进入 `/teacher`。
- 管理员登录：进入 `/dashboard`。

切换角色时，请从侧边栏底部返回登录页后重新选择角色。

## 2. 学生端使用

推荐路线：

1. `/student` 查看学习总览。
2. `/student/courses` 查看我的课程。
3. `/student/learning-path` 查看学习路径。
4. `/student/assistant` 使用智能辅导，查看画像对话、资源包、RAG 引用回答、防幻觉审核。
5. `/student/exams` 查看测验成绩。
6. `/student/reports` 查看学习报告。

学生端重点展示个人学习闭环：发现薄弱点、获取路径、获得资源、练习测验、查看报告。

## 3. 教师端使用

推荐路线：

1. `/teacher` 查看班级概览。
2. `/courses` 管理课程。
3. `/profiles` 查看学生画像。
4. `/learning-path` 查看学习路径与任务布置。
5. `/teacher-analysis` 查看测评分析。
6. `/reports` 查看报告中心。

教师端重点展示教学干预闭环：识别学生问题、调整任务、观察测评结果、形成报告。

## 4. 管理员端使用

推荐路线：

1. `/dashboard` 查看平台总览。
2. `/admin/users` 查看用户与角色。
3. `/admin/courses` 查看课程治理。
4. `/resource-generation` 查看资源生成与 AI 内容审核。
5. `/agent-workflow` 查看 Agent 执行链路。
6. `/logs` 查看日志管理。
7. `/settings` 查看系统设置。
8. `/demo-status` 查看比赛演示状态。

管理员端重点展示平台治理闭环：角色、课程、资源、Agent、日志、状态检查。

## 5. 小程序使用

用微信开发者工具导入 `miniprogram` 目录后，可体验：

- 今日学习：首页展示学习进度和任务。
- 学习路径：查看阶段化学习安排。
- 资源推荐：查看个性化资源包。
- AI 辅导：优先请求 RAG 接口，展示引用来源和推荐练习；后端不可用时使用本地数据。
- 学习报告：查看移动端学习总结。

## 6. demo-status 使用

访问 `/demo-status` 检查：

- Web 三端 Ready。
- 小程序学生端 Ready。
- 对话式画像 Ready。
- 8 类资源生成 Ready。
- 课程知识库 Ready。
- RAG 引用来源 Ready。
- 防幻觉审核 Ready。
- Agent 执行链路 Ready。

## 7. 使用边界

当前系统为比赛演示版本，采用轻量 RAG 和规则化 Agent 编排。它展示了完整产品思路和可运行闭环，但没有声称接入真实大模型 API，也没有声称已经正式上线。
