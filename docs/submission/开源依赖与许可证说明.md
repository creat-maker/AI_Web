# EduMind 开源依赖与许可证说明

## 1. 说明范围

本文档用于比赛提交材料整理，说明 EduMind 当前版本涉及的主要开源技术栈和使用边界。最终提交前建议以 `frontend/package.json`、`backend/requirements.txt` 为准再次核对依赖版本和许可证。

## 2. 前端主要依赖

Web 前端主要使用：

- Vue 3：前端 UI 框架。
- Vite：前端构建工具。
- TypeScript：类型约束。
- Vue Router：前端路由。
- ECharts：图表展示。

这些依赖均为常见开源前端依赖，通常适用于学习、比赛和工程开发场景。提交材料中建议保留 `package.json` 和锁文件，便于评审复现。

## 3. 后端主要依赖

后端主要使用：

- FastAPI：Web API 框架。
- SQLAlchemy：数据库 ORM。
- Pydantic / Pydantic Settings：数据校验与配置管理。
- Uvicorn：ASGI 服务运行。

当前后端默认使用 SQLite 本地演示库，不依赖外部数据库即可完成基础演示。

## 4. 小程序依赖

小程序为原生微信小程序结构，不使用 uni-app、Taro 或其他跨端框架，不额外引入复杂依赖。

## 5. AI 与检索依赖

当前版本未引入：

- LangChain
- LangGraph
- Chroma
- FAISS
- 真实大模型 API SDK

RAG 和 AgentWorkflow 均为项目内轻量规则实现，便于本地演示和答辩解释。

## 6. 许可证注意事项

提交前建议检查：

- `frontend/package.json`
- `backend/requirements.txt`
- 第三方图标或图片来源
- 演示视频和 PPT 中使用的素材来源

不要在提交包中包含未授权商业素材、真实 API Key、真实学生隐私数据或未脱敏日志。

## 7. 提交建议

建议提交源码、文档、演示数据和验收报告，不提交：

- `node_modules`
- `frontend/dist`
- `.env`
- 本地数据库文件
- 上传文件
- 运行日志
- 缓存目录
