# EduMind 部署运行说明

## 1. 目录结构

项目根目录包含：

- `backend`：FastAPI 后端服务。
- `frontend`：Vue 3 Web 前端。
- `miniprogram`：原生微信小程序学生端体验版。
- `docs`：文档、知识库和提交材料。
- `reports`：验收脚本输出报告。
- `scripts`：演示数据初始化与验收脚本。

## 2. 后端启动

进入后端目录并安装依赖：

```bash
cd backend
pip install -r requirements.txt
```

启动服务：

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

健康检查：

```bash
curl http://127.0.0.1:8000/health
```

## 3. 前端启动

进入前端目录并安装依赖：

```bash
cd frontend
npm install
```

启动开发服务：

```bash
npm run dev
```

默认访问地址：

- 登录页：`http://127.0.0.1:5173/login`
- demo-status：`http://127.0.0.1:5173/demo-status`

## 4. 演示数据初始化

```bash
python scripts/seed_demo_data.py
```

Windows 可使用：

```bat
seed-demo-data.bat
```

## 5. 一键启动与停止

Windows 环境可使用：

```bat
start-dev.bat
stop-dev.bat
```

## 6. 小程序运行

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择 `miniprogram`。
4. 本地体验可使用测试号或无 AppID 模式。
5. 后端地址默认在 `miniprogram/utils/request.js` 中配置为 `http://127.0.0.1:8000`。

## 7. 构建与验收

前端构建：

```bash
cd frontend
npm run build
```

演示状态检查：

```bash
python scripts/check-demo-ready.py --backend-url http://127.0.0.1:8000 --frontend-url http://127.0.0.1:5173
```

端到端检查：

```bash
python scripts/e2e_demo_flow_check.py --base-url http://127.0.0.1:8000 --output reports/demo_flow_check.md
```

## 8. 注意事项

- 不需要配置真实大模型 API Key。
- 不需要启动向量数据库。
- 不要提交 `.env`、数据库文件、上传文件、日志、`node_modules`、`dist`。
- 比赛现场建议提前完成依赖安装和演示数据初始化。
