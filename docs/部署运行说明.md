# 部署运行说明

本文档用于本地演示和比赛录制前验收。项目根目录为 `EduMind`。

## 一、后端运行

推荐使用项目 `.venv`：

```bash
.\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --reload
```

如果在 `backend` 目录内运行：

```bash
cd backend
..\.venv\Scripts\python.exe -m uvicorn app.main:app --reload
```

注意：上方命令中的虚拟环境路径应按实际 PowerShell 路径确认。

## 二、前端运行

```bash
cd frontend
npm.cmd run dev
```

构建检查：

```bash
cd frontend
npm.cmd run build
```

说明：PowerShell 下 `npm run build` 如遇执行策略限制，使用 `npm.cmd run build`。

## 三、小程序运行

1. 打开微信开发者工具。
2. 导入项目根目录下的 `miniprogram/`。
3. 检查首页、路径、资源、学伴、测验、报告、画像对话页面。
4. 确认小程序口径统一为 Python 程序设计 / 循环结构 / 李明画像。

小程序端不需要新增第三方 UI 库。

## 四、推荐验收路径

1. 登录页选择“李明 / 基础薄弱 + 代码实操偏好型”进入学生端。
2. 查看学生首页学习驾驶舱。
3. 进入对话式画像构建页。
4. 查看学习路径与资源生成页。
5. 进入 AI 学伴，默认问题使用“为什么我的 while 循环会死循环？”。
6. 查看形成性评价报告。
7. 切换教师端查看循环结构学情分析。
8. 切换管理员端查看内容审核和教学决策中心。

## 五、环境变量说明

- `TTS_API_KEY`：TTS 或数字人讲解脚本能力预留。
- `DIGITAL_HUMAN_API_KEY`：数字人 API 预留。

未配置以上变量时，相关能力使用 mock fallback。当前项目不得将数字人描述为完整实时数字人系统，只能描述为“数字人讲解脚本 / TTS 或数字人 API 预留”。
