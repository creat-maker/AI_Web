# EduMind 系统开发说明

## 1. 项目概述

EduMind 是面向比赛演示的教育智能体系统，围绕学生学习、教师教学干预、管理员平台治理构建 Web 三端，并提供原生微信小程序学生端体验版。系统当前定位为本地可运行、可演示、可验收的稳定版本，不声称已正式上线。

系统重点展示以下能力：

- 学生端学习闭环：课程、学习路径、AI 辅导、测验、报告。
- 教师端教学干预闭环：班级概览、课程管理、学生画像、任务路径、测评分析、报告。
- 管理员端治理闭环：用户、课程、资源生成、AgentWorkflow、日志、系统设置、demo-status。
- 移动端体验：原生微信小程序学生端，支持本地 demoData fallback。
- AI 能力演示：对话式画像、8 类资源生成、轻量 RAG 引用、防幻觉审核、规则化 Agent 执行链路。

## 2. 技术架构

- 前端 Web：Vue 3、Vite、TypeScript、Vue Router、ECharts。
- 后端服务：FastAPI、SQLAlchemy、Pydantic Settings。
- 数据存储：默认 SQLite 本地演示库，保留 MySQL 配置扩展空间。
- 小程序：原生微信小程序，不使用 uni-app 或 Taro。
- AI 演示能力：规则生成、关键词检索、引用覆盖检查、规则化 Agent 编排。
- 课程知识库：`docs/course_kb/python_programming.json`，稳定可读 JSON 数据。

## 3. 模块划分

### Web 三端

- 学生端：`/student`、`/student/courses`、`/student/learning-path`、`/student/assistant`、`/student/exams`、`/student/reports`。
- 教师端：`/teacher`、`/courses`、`/profiles`、`/learning-path`、`/teacher-analysis`、`/reports`。
- 管理员端：`/dashboard`、`/admin/users`、`/admin/courses`、`/resource-generation`、`/agent-workflow`、`/logs`、`/settings`。

### 后端接口

- 基础演示接口：课程、画像、路径、资源、报告、日志、demo-status。
- 对话式画像：`POST /api/v1/profile-dialog/run`。
- 8 类资源生成：`POST /api/v1/resources/generate-pack`。
- RAG 引用问答：`POST /api/v1/rag/ask`。
- 内容审核：`POST /api/v1/content-review/check`、`GET /api/v1/content-review/records`。

### 小程序

小程序目录为 `miniprogram`，包括今日学习、学习路径、资源推荐、AI 辅导、练习错题、学习报告页面。默认使用本地 `utils/demoData.js`，请求失败时不影响现场演示。

## 4. AI 能力实现说明

当前版本不接入真实大模型 API，不使用向量数据库，也不引入 LangChain、LangGraph、Chroma、FAISS 等复杂依赖。AI 能力采用稳定可解释的规则化实现：

- 画像构建：基于自然语言回答中的目标、薄弱点、时间安排、偏好等关键词生成画像维度。
- 资源生成：根据学生、课程、薄弱点生成讲义、练习题、代码案例或实验任务、思维导图文本、视频脚本或项目任务书。
- RAG 检索：基于课程知识库做关键词匹配和规则排序，返回答案与引用来源。
- 防幻觉审核：检查引用覆盖、无引用风险、绝对化承诺和无依据结论。
- AgentWorkflow：以规则化流程展示画像构建、知识检索、路径规划、资源生成、内容审核、学习报告。

## 5. 可扩展方向

当前架构保留后续扩展空间，可平滑接入：

- 生产级鉴权和角色权限。
- 真实大模型 API。
- 向量数据库或文档检索服务。
- 持久化内容审核记录。
- 浏览器自动化端到端测试。
- 小程序真实 AppID 发布流程。
