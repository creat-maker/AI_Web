# EduMind AI 工具使用说明

## 1. 使用原则

EduMind 当前版本不接入真实大模型 API，不存储真实 API Key，不使用外部在线推理服务。系统采用轻量、稳定、可解释的规则化 AI 演示方案，保证比赛现场离线或弱网络环境下仍可展示核心能力。

## 2. 对话式学习画像

接口：`POST /api/v1/profile-dialog/run`

输入学生自然语言回答，系统根据目标、基础、薄弱点、偏好、时间安排、风险等关键词生成学习画像。

输出维度包括：

- 学习目标
- 基础水平
- 薄弱知识点
- 学习偏好
- 时间安排
- 学习风险
- 推荐策略

## 3. 5 类个性化资源生成

接口：`POST /api/v1/resources/generate-pack`

输入学生 ID、课程 ID、薄弱点后，生成：

- 个性化讲义
- 练习题
- 代码案例或实验任务
- 思维导图文本
- 视频脚本或项目任务书

每类资源包含资源类型、标题、内容、推荐理由、相关知识点、难度和预计学习时长。

## 4. 轻量 RAG 引用问答

接口：`POST /api/v1/rag/ask`

当前实现基于 `docs/course_kb/python_programming.json` 做关键词匹配和规则排序，不使用向量数据库。接口返回回答、引用来源、匹配片段、可信度、推荐练习和相关知识点。

引用来源包含：

- sourceFile
- chapter
- section
- snippet

## 5. 防幻觉审核

接口：

- `POST /api/v1/content-review/check`
- `GET /api/v1/content-review/records`

审核规则：

- 没有引用来源：风险至少为 `medium`。
- 引用覆盖不足：给出 warning。
- 包含“保证、一定、百分百、绝对”等夸张承诺或无依据结论：给出 hallucinationWarning，必要时阻断。

## 6. Agent 执行链路

AgentWorkflow 页面展示规则化六步链路：

1. 画像构建
2. 知识检索
3. 路径规划
4. 资源生成
5. 内容审核
6. 学习报告

每一步展示输入、输出、耗时和状态，用于说明教育智能体如何串联学生画像、课程知识库、资源生成与审核。

## 7. 与真实大模型的关系

当前版本没有接入真实大模型 API。后续可以在保持接口结构稳定的基础上扩展：

- 将画像生成替换为大模型结构化抽取。
- 将资源生成替换为大模型生成。
- 将轻量 RAG 升级为向量数据库检索。
- 将内容审核升级为规则审核和模型审核结合。
- 将规则化 Agent 编排升级为生产级工作流编排。
