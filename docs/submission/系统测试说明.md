# EduMind 系统测试说明

## 1. 测试目标

本测试说明用于比赛提交和答辩验收，目标是证明 EduMind 当前版本具备本地可运行、核心路由可访问、演示数据可用、AI 演示链路可闭环的能力。

## 2. 测试范围

- Web 三端核心页面访问。
- 后端健康接口和核心 API。
- demo-status 状态检查。
- 对话式画像接口。
- 5 类资源生成接口。
- RAG 引用问答接口。
- 防幻觉内容审核接口。
- AgentWorkflow 页面展示。
- 小程序本地 demoData fallback 展示。

## 3. 测试环境

- 操作系统：Windows 本地开发环境。
- 后端：FastAPI，默认端口 `8000`。
- 前端：Vite dev server，默认端口 `5173`。
- 数据库：SQLite 本地演示库。
- 小程序：微信开发者工具导入 `miniprogram` 目录。

## 4. 自动化验收命令

前端构建：

```bash
cd frontend
npm run build
```

演示状态检查：

```bash
python scripts/check-demo-ready.py --backend-url http://127.0.0.1:8000 --frontend-url http://127.0.0.1:5173
```

端到端演示流检查：

```bash
python scripts/e2e_demo_flow_check.py --base-url http://127.0.0.1:8000 --output reports/demo_flow_check.md
```

## 5. 新增 AI 接口结构检查

RAG 引用问答：

```bash
curl -X POST http://127.0.0.1:8000/api/v1/rag/ask ^
  -H "Content-Type: application/json" ^
  -d "{\"question\":\"递归题应该怎么分析？\",\"courseId\":\"python-programming\",\"studentId\":\"demo-student-zhangsan\"}"
```

内容审核：

```bash
curl -X POST http://127.0.0.1:8000/api/v1/content-review/check ^
  -H "Content-Type: application/json" ^
  -d "{\"courseId\":\"python-programming\",\"content\":\"递归函数必须包含递归出口。\",\"citations\":[{\"sourceFile\":\"python_ch02_functions.md\",\"chapter\":\"第 2 章 函数与模块化\",\"section\":\"递归基础\",\"snippet\":\"递归函数必须包含递归出口。\"}]}"
```

## 6. 通过标准

- `npm run build` 成功完成。
- `check-demo-ready.py` 总体状态为 `READY` 或不影响演示的 `WARNING`。
- `e2e_demo_flow_check.py` 核心流程全部通过。
- `/api/v1/demo-status` 显示 Web 三端、小程序、画像、资源生成、课程知识库、RAG、防幻觉审核、Agent 执行链路为 Ready。
- Web 核心页面 HTTP 状态为 200。
- 小程序不依赖后端也可展示核心页面。

## 7. 已知边界

- 当前不接真实大模型 API。
- 当前 RAG 为轻量关键词检索，不是向量数据库检索。
- 当前 AgentWorkflow 为规则化编排演示，不是生产级工作流引擎。
- 内容审核记录当前适合演示，不作为生产审计系统。
