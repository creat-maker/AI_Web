# 演示脚本

主演示主线：课程为《Python 程序设计》，章节为“循环结构”，知识点为 for 循环、while 循环、break / continue、循环嵌套；学生为李明，画像为“基础薄弱 + 代码实操偏好型，中风险”。

## 7 分钟演示路线

### 0:00 - 0:40 平台定位与痛点

说明传统教学中学生差异难以及时识别、资源推送不够精准、教师干预缺少证据链。引出 EduMind：围绕 A3 个性化教学质量提升，构建从画像、资源、路径、答疑、评价到审核决策的闭环。

### 0:40 - 1:30 对话式画像

进入李明学生端或画像页，展示系统如何通过对话收集学习目标、当前水平、薄弱点、偏好和风险因素。强调结果：李明是“基础薄弱 + 代码实操偏好型，中风险”，薄弱点集中在 while 循环、循环嵌套和 break / continue。

### 1:30 - 2:30 多智能体资源生成

进入资源生成页，展示针对李明生成的 Python 循环结构个性化补弱资源包。说明资源包含讲解文档、代码实操案例、专项练习、视频脚本等。强调所有资源围绕课程知识库和学生画像生成，并进入审核流程。

### 2:30 - 3:20 Agent 工作流

进入 Agent 工作流页，展示画像分析、RAG 检索、路径规划、资源生成、AI 学伴、测评评价、内容审核、报告生成等步骤。说明这是多智能体协同链路，输出结果可追溯，不是单点问答。

### 3:20 - 4:10 一人一堂学习路径

进入学习路径页，展示李明的循环结构补弱路径：while 循环终止条件、break / continue 对比、循环嵌套变量追踪。强调路径会根据测验错因和资源完成情况动态调整。

### 4:10 - 5:00 诊断式 AI 学伴

进入 AI 学伴页，提问“为什么我的 while 循环会死循环？”。展示回答不仅解释原因，还给出变量变化表、代码检查步骤和下一步练习。说明 AI 回答基于 Python 程序设计课程知识库，并提示低证据内容需复核。

### 5:00 - 5:40 形成性评价报告

进入报告中心，展示“李明 Python 循环结构形成性评价报告”。讲解正确率、错题知识点、错因分析、能力维度评分、AI 学习建议、下一步路径、资源调整策略和教师干预建议。

### 5:40 - 6:20 内容审核与教学决策中心

进入管理员内容审核页，展示状态统一为通过、需修改、人工复核、风险拦截。再进入教学决策中心，说明平台如何帮助教师和管理员查看风险学生、资源质量、干预建议和 AI 使用边界。

### 6:20 - 7:00 小程序与总结

展示小程序端：学生学习驾驶舱、一人一堂路径、资源包、AI 学伴、测验和报告。总结 EduMind 的价值：用大模型和多智能体把“看见差异、生成资源、精准干预、持续评价、安全审核”串成可演示、可追溯的教学质量提升闭环。
