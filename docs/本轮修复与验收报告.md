# EduMind 本轮修复与验收报告

## 1. 审计发现

本轮基于当前仓库重新审计，而不是假定上一轮代码仍然完整存在。

- 当前仓库存在外层项目与未跟踪内层 `EduMind/` 目录，实际修复对象为外层 `C:\Users\26805\Desktop\EduMind`。
- 登录页为旧版本，只有角色卡片，没有真实账号密码表单，也没有调用后端登录接口。
- 路由缺少 `/student/resources`、`/admin/resource-generate`、`/account-settings`、`/help-center`、`/unauthorized`，且缺少 session 路由守卫。
- 课程页面存在静态兜底数据和损坏文案，新建课程入口不完整，课程编号、章节数、状态、标签无法被后端安全接收。
- 资源生成接口 `generate-pack` 只返回资源包并记录事件，没有把生成资源写入 `GeneratedResource`，导致学生端刷新后可能看不到生成结果。
- 学生课程页是静态数据，未调用学生课程聚合接口。
- 学生资源页、管理员资源生成页、个人中心、账号设置、帮助中心、无权限页缺失。
- 报告后端和报告服务层存在损坏文案，报告中心、管理员报告中心按钮多为静态行为。
- 用户与角色页面是静态数组，启用/禁用、重置密码、分配角色、权限保存没有真实接口行为。
- 顶部栏个人中心、账号设置、帮助按钮没有真实跳转，全局搜索只保存关键词，没有产生可见结果。
- `frontend/src` 中残留的用户可见旧词已清理；文档审计记录中仍保留旧词作为历史问题清单。

## 3. 登录与权限链路

- 登录页改为正式左右分屏教育 SaaS 风格。
- 支持学生、教师、管理员三角色快捷登录。
- 支持手动账号密码登录。
- 登录调用 `/api/v1/auth/login`。
- 成功后写入 `edumind.accessToken`、角色和用户标识。
- 路由守卫根据本地 session 和当前角色判断是否可访问目标页面。
- `/demo-status` 和 `/capability-boundary` 保持为公开可读辅助入口，登录页可直接打开。

可用账号：

- `student / 123456`
- `teacher / 123456`
- `admin / 123456`
- 兼容原 `demo_student`、`demo_teacher`、`demo_admin`

## 4. 课程创建闭环

课程管理页现在支持：

- 点击“新建课程”打开表单弹窗。
- 表单字段包括课程名称、课程编号、授课教师、简介、章节数、状态、知识点标签、学科。
- 必填项校验：课程名称、课程编号、授课教师。
- 提交调用 `POST /api/v1/courses`。
- 后端写入 SQLite 的 `Course` 表。
- 课程编号、章节数、状态、标签在不改数据库结构的前提下合并到 `description`，避免迁移风险。
- 提交成功后关闭弹窗、提示成功、刷新课程列表。
- 刷新页面后课程仍存在。
- 搜索可按课程名称、编号、教师、状态、学科、简介、知识点过滤。
- 管理员课程治理复用同一真实课程管理链路。

## 5. 资源生成与学生读取闭环

管理员资源生成中心：

- 新增 `/admin/resource-generate` 页面。
- 调用 `/api/v1/courses` 加载真实课程下拉框，新建课程可出现在这里。
- 调用 `/api/v1/resources/generate-pack` 生成资源包。
- 后端将资源写入 `GeneratedResource`，并按课程和标题去重。
- 资源列表调用 `/api/v1/resources`。
- 搜索支持课程、资源类型、状态、标题、内容、难度、推荐理由等字段。

学生资源页：

- 新增 `/student/resources` 页面。
- 调用 `/api/v1/courses` 和 `/api/v1/resources`。
- 搜索支持课程、资源类型、标题、知识点、状态、内容。
- 搜索“循环”可命中 Python 循环结构相关资源。
- 无结果时显示“未找到相关资源”，不会静默无反应。

## 6. 报告闭环

后端：

- 重写报告 router，保留 `/api/v1/reports`、`/api/v1/reports/generate`、`/api/v1/reports/{id}/download`、`/api/v1/reports/summary`。
- 重写报告服务层，生成可读的学习诊断报告文档。
- 新增管理员报告接口 `/api/v1/admin/reports`、预览、下载、重新生成、生成月报、批量导出、状态更新。

前端：

- 教师报告中心调用真实报告列表。
- 支持搜索、查看预览、导出报告、重新生成。
- 管理员报告审核中心支持搜索、预览、导出、重新生成、生成月报、批量导出、通过审核。
- 新增 `ReportPreviewModal.vue` 统一展示摘要、关键结论、薄弱知识点、证据链。

## 7. 用户与角色闭环

- 新增 `/api/v1/admin/users` 与 `/api/v1/admin/roles`。
- 用户状态、角色、重置密码、权限保存使用 JSON fallback storage 持久化。
- 用户与角色页面支持按姓名、账号、角色、学习水平、风险等级、班级、组织、状态搜索。
- 启用/禁用、分配角色、重置密码、保存权限都调用后端接口。
